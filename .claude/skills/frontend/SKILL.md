# Frontend — Angular 20 SPA — `frontend`

**Does:** The single-page app of the student-government platform. It holds the public apply wizard + status timeline, a role-aware dashboard, and full screens for applications, voting (live-vote/beamer/cast) and meetings (agenda/attendance/protocol). It also covers budget/expenses/invoices, account, and the admin config surface. Standalone components, signals, lazy permission-gated routes, typed API client over `/api`.

**Key files:**
- `src/app/app.config.ts` — composition root: interceptor chain `[loading, auth, mock?]` (mock added only in `isDevMode()`), `provideFormly`, `provideAppInitializer` (theme/i18n/branding/auth/sw), service worker (prod only), `LIVE_VOTE_SOURCE` factory.
- `src/app/app.routes.ts` — all routes sit under `ShellComponent`. Each route uses lazy `loadComponent`, `canActivate: [authGuard]`, `data.permission` and flags (`allowAuthenticated`, `allowCommitteeMember`, `allowScopedBudgetView`, `wide`, `parent`, `title`, `contextual`, `chrome: false` = no frame, used by the beamer routes; a bare page must give its own way back, the beamer leaves on Escape and has an exit link that shows on a pointer movement or on focus and hides when the pointer rests). The permission lists `VOTING_GREMIUM_PERMISSIONS`, `BUDGET_PERMISSIONS`, `ADMIN_AREA_PERMISSIONS` live in `layout/nav.service.ts`, so the nav and the guards use the same keys.
- `src/app/core/api/api-client.service.ts` — typed HTTP facade (`ApiClient`) that returns `Observable<…>`. One method per backend route.
- `src/app/core/api/api.config.ts` — `API_BASE_URL` token (`/api`) and `USE_MOCK_API` token (default false). Opt in to the mock with `?mock=1`, `localStorage['useMockApi']` or `window.__USE_MOCK_API__`.
- `src/app/core/api/models.ts` — all DTO interfaces + `*Wire` raw shapes. `mappers.ts` converts wire→domain. `delegations.service.ts` = delegation API.
- `src/app/core/api/mock-api.interceptor.ts` — in-memory backend for dev/tests only. Meetings: the live one (`d…0001`: keeper periods, handover now/next item, a delegation of the meeting that blocks "present", O23), the planned one (`d…0002`) and two closed ones in the lazy `mock-meetings-closed.ts` (`d…0101` draft protocol, `d…0102` final protocol with both PDFs). The participant view comes from the lazy `mock-meetings-member.ts`: `d…0003` is the live meeting as a plain member sees it (Max Mustermann keeps the minutes, the demo user represents Erika Beispiel), `d…0105` a planned meeting of the timeline with its agenda; it also answers the delegation context and the recipients of every meeting (two substitutes, five members), and `POST /delegations` adds an own delegation. Votes: `GET /votes/{id}` gives the demo vote (item 3 of `d…0001`, hidden counts) under any id, with the ballots of the mock session; a second ballot of the same row is a 409 `already_voted`; the delegation status of every vote says the demo user represents a member, so the ballot shows both rows. `localStorage['mockAnonymous'] = '1'` plays a visitor without a session (`/auth/me` → 401: public frame, wizard with contact step and ALTCHA). The demo type `11111111-…` gets the form of the demo applications; `POST`/`DELETE /apply/attachments` answer like the server (token `mock-draft-token`).
- `src/app/core/auth/{auth.service,auth.guard,auth.interceptor}.ts` — `AuthService.can()/canAny()`, OIDC login/logout, session cookie/magic-link. The guard reads `route.data.permission` and redirects to `/forbidden`. The interceptor adds credentials and handles 401.
- `src/app/core/i18n/{i18n.service,translations,translate.pipe,localized-date.pipe}.ts` — DE/EN catalog, signal locale (stored→browser→DE fallback), `translate(key, params)`, `t`/`localizedDate` pipes. `ldate` presets: `short`, `medium`, `mediumDate`, `long`, `time`, `weekdayDate` ("Di., 13.10.2026") and `weekdayShort` ("Di., 13.10.2026, 17:00", 24 h).
- `src/app/core/theme/theme.service.ts` — `ThemePreference` light/dark/system. The service sets `data-theme` on `<html>`, follows the OS through matchMedia, and persists the choice. `setPageDefault(theme | null)`: the theme that `system` gives while one page shows (the beamer: dark); an explicit choice still wins, and the value is not persisted.
- `src/app/core/branding/branding.service.ts` — `appName` comes from site-config, else from the i18n key `app.title`. The service sets `document.title`. It also holds the public values of `GET /site-config`: `confirmTtlHours` (default 12), `linkTtlDays` (`null` = links do not expire, the default), `attachmentLimits` (`maxFileBytes`, `maxDraftFiles`, `maxDraftBytes`; backend defaults until the config loads) and the `freetexts` of the branding (`welcome`, `applyInfo`, …).
- `src/app/core/loading/{loading.service,loading.interceptor}.ts` — global overlay counter. Opt out per request with `SKIP_LOADING_HEADER` (`X-Skip-Loading`).
- `src/app/core/ws/{ws.service,live-vote.service,live-vote.source,mock-live-vote.source,ws-messages}.ts` — `/api/ws/meetings/{id}` (+`/beamer` read-only) live-vote channel. `LIVE_VOTE_SOURCE` selects the mock source or the real one. The mock source hides the counts like the server until every present member voted (`cast`, `present`, `revealed`), and offers `globalThis.__stupaMockLive.push(frame)` to screenshot scripts (mock mode only).

**Conventions & gotchas:**
- Standalone components, `OnPush`, signals. Use **separate `.html`/`.scss` files** (no inline templates). Components use **only Semantic tokens** (`--color-*`), never Primitives (`--c-*`). Add a primitive first, then map it per theme. Theme goes on `<html>` as `data-theme`.
- Routes are lazy + permission-gated: set `data.permission` (global keys, string or array → OR) and/or `data.gremiumPermission` (gremium keys such as `session.manage`, held in ANY gremium, or admin), plus `allowCommitteeMember`/`allowScopedBudgetView`/`allowAuthenticated` to widen. Missing permission → `/forbidden`. The backend also enforces RBAC. The guard is UX only.
- Gremium rights never sit in `principal.permissions`, so `auth.can('session.manage')` is always false for a non-admin. Use `auth.canInGremium(gid, perm)` / `auth.canInAnyGremium(perm)` (from `/auth/me` `gremium_permissions`) or, per meeting, the server flags `canManage`/`canWrite`/`canManageVotes`/`canFinalize`. `auth.isAdmin()` replaces the former global `meeting.manage` check. The same holds for the voting keys: `vote.cast` and `vote.manage` are gremium-only (no global key since `b0c8fd389e10`), so the voting routes use `gremiumPermission: ['vote.cast', 'vote.manage', 'session.manage']` and components use the server flags, never `auth.can('vote.*')`.
- Design rules (binding, see `DESIGN_SYSTEM.md`): one accent colour, a status is coloured text (no dot, no pill), a tag is a feature and not a status, a destructive action is an outlined red button (`variant="danger"`), fill or center, no noise text, input fields without shadow, long names with `.ell` plus `title`, avatars only for persons.
- Never show raw UUIDs in UI — resolve to names server-side ([[no-uuids-in-ui]]). Use the global `.empty-state` utility for empty tables/lists ([[empty-state-convention]]).
- The loading overlay is **GET-driven**. Mutations, polls and typeahead opt out with the `X-Skip-Loading` header or `skipLoading()` ([[loading-overlay-convention]]). Toasts go through `ToastService`.
- All errors come back as `application/problem+json` (`ProblemDetail`). Show them with a toast.
- The app registers the mock interceptor **only in dev builds** (`isDevMode()`). Prod talks to the real `/api`. WS goes through nginx/`proxy.conf.json` in dev.
- **Bundle budgets:** run `npm run build` after component CSS/template changes — jest+tsc miss the per-component style budget that fails the Docker/prod build ([[ng-build-budgets]]). Import `MarkdownEditorComponent` by path, not the ui barrel.
- Edit i18n in BOTH `de` and `en` catalogs in `core/i18n/translations.ts`. Configurable DB texts (`*_i18n`) are NOT in I18nService.
- Commands: `npm start` (dev :4200), `npm run build` (→ `dist/antragsplattform/browser`), `npm test` (jest), `npm run test:cov` (FE coverage gate), `npm run lint`, `npm run typecheck`, `npm run e2e` (playwright).
