The user repeatedly asks for admin UIs that look and work like their Nextcloud counterparts. Two named examples: the **user list as the Nextcloud users table**, and the **Form-Builder ~1:1 like Nextcloud Forms**.

**Why:** Nextcloud is the team's reference for good, non-clunky admin UX. The recurring complaints are "clunky", "cluttered" and "makes no sense".

**How to apply:** when you build or rework an admin screen, look at the Nextcloud equivalent first (user management table, Forms question editor). Match its layout and interaction model: table-based lists, per-row actions, drag-reorder and inline editors. Do not fall back to ad-hoc forms. See [[antragsplattform-backlog]].
