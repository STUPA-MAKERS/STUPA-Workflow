# The activity page loads 50 events per step without a time limit

The page must load 50 events per step, newest first, and load the next 50 when the person
scrolls to the end. The paging must use the time and the id of the last event as the cursor, not
an offset. The page must not limit how far back it goes.

Reason: An old Antrag stays findable, and a new event between two steps does not shift or repeat
a row.
