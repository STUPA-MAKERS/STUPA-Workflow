# A Termin has a title and a time span

A Termin must have a title, a start and an end, and can have a place and a description. A
Termin is all-day or timed. The end must not be before the start, and a Termin can span several
days. The German UI calls it `Termin`, the English UI calls it `Appointment`.

Reason: A date that is not a meeting, not a deadline and not an Event has no place in the
platform today.

Test: A backend unit test creates an all-day Termin over three days and refuses an end before
the start.
