# The pretix actions write audit entries

The link and the unlink of a pretix event and each change of the
connection must write an audit entry with the Event and the person.

Reason: The link decides which sales the platform shows for an Event, so a later reader must
see who set it.

Test: A backend unit test links a pretix event and reads the audit entry.
