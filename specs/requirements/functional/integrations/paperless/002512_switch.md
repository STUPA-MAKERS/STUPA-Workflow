# The Paperless integration has one switch

The admin page `Paperless` must have one switch for the integration. While the switch is off or
the connection has no address, the platform must not call Paperless and must not show an
element of the integration.

Reason: An integration is optional (000176). One switch stops it without the loss of its
settings.

Test: A unit test finalizes a protocol with the switch off and expects no job for Paperless.
