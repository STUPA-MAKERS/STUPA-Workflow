# Each part of the Paperless integration has its own switch

The admin page `Paperless` must have one switch for each of these parts: `Protokolle ablegen`
(002516), `Anträge ablegen` (003110), `Haushaltspläne ablegen` (002518) and `Aus Paperless
einfügen` (002527). Each switch must start off. While a switch is off or the connection has no
address, the platform must not call Paperless for that part and must not show an element of
it.

Reason: An integration has a switch per feature (000176). An admin can file the protocols and
keep the Anträge out of the archive.

Test: A unit test finalizes a protocol with the switch `Protokolle ablegen` off and expects no
job for Paperless.
