# Each filing and each insert has an audit entry

The platform must write an audit entry for each document that it files in Paperless and for
each insert from Paperless. The entry must name the element and the number of the Paperless
document. A change of the connection must also write an audit entry, without the token.

Reason: A copy leaves the platform or enters it. The audit log must show who caused it and
when.

Test: A unit test files a document and expects the audit entry.
