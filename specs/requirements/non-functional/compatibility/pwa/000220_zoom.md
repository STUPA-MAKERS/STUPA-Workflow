# Zoom is blocked only in the installed app

The installed PWA blocks pinch zoom. The browser tab must allow zoom, so the viewport meta tag
must not contain `user-scalable=no`.

Test: `frontend/src/app/core/pwa/install-metadata.spec.ts`.
