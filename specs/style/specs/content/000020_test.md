# A rule names its test

Add `Test:` with the test, lint rule or check that finds a violation. Leave it out if only a
review can find a violation. If a unit test checks the rule, also list it in `tests` in the
front matter.

Reason: `tests` lets a tool find the tests of a rule and run them.
