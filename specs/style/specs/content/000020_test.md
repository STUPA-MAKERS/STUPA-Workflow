# A rule names its test

A rule must have `Test:` with the test, lint rule or check that finds a violation. It can leave
the label out if only a review can find a violation. If a unit test checks the rule, the test
must also be in `tests`.

Reason: `tests` lets a tool find the tests of a rule and run them.
