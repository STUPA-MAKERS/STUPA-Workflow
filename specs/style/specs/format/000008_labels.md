# Labels in a rule are fixed

A spec must use only these labels, each at the start of its own paragraph:

- `Reason:` the cause of the rule.
- `Test:` how a person or a tool finds a violation.

Other text is the rule text. It comes before the labels.

Test: `scripts/check_specs.py`: the labels are `Reason`, then `Test`, once each.
