# The status shows the approval

| Status | Meaning |
| --- | --- |
| `draft` | Not yet approved by the owner. Follow it, but ask when it blocks you. |
| `approved` | The owner approved it. Follow it. |
| `replaced` | A different rule replaces it. `replaced_by` names that rule. |
| `removed` | The rule is not in force. The file stays, so that the number stays taken. |

Only the owner sets `approved`.
