# The rule ID has kind, path and number

The rule ID has the form `(F|NF|S)/<path>/NNNNNN`:

- `F` is a functional requirement, `NF` a non-functional requirement, `S` a style rule.
- `<path>` is the folder path of the file below its kind folder, with `/` between the parts.
  A file in `requirements/functional/meetings/voting/` gives `meetings/voting`.
- `NNNNNN` is the six-digit number from the file name.

Examples: `F/meetings/voting/000024`, `S/specs/format/000005`.

Test: `id` matches `^(F|NF|S)(/[a-z0-9-]+)+/[0-9]{6}$`, and kind, path and number match the
file path.
