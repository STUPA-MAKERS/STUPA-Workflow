# The index lists every rule

`specs/README.md` must list every rule with its ID, title and status, sorted by ID. A pull
request that adds, moves or removes a rule must update the index with `python3
scripts/check_specs.py --write`.

Test: `scripts/check_specs.py` fails when the index or the tree in `specs/README.md` is not
current.
