# A UI change is approved on screenshots

Before the merge of a UI change, an agent must show current screenshots to the owner and wait
for the OK. The screenshots must show the change also in the display settings of the
accessibility menu, for example "Hoher Kontrast". Screenshots must not be committed to the repository.
